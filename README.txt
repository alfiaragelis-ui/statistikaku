STATISTIKAKU — WEBSITE STATISTIKA DESKRIPTIF

Cara mencoba:
1. Ekstrak ZIP.
2. Buka folder StatistikaKu_Website.
3. Klik dua kali index.html.
4. Klik "Coba dengan data contoh" untuk menguji fitur.

Fitur:
- Unggah CSV dan Excel (.xlsx/.xls)
- Data contoh
- Jumlah data, rata-rata, median, modus, minimum, maksimum
- Varians populasi dan simpangan baku
- Pratinjau tabel
- Histogram dan grafik frekuensi
- Unduh data sebagai CSV

Catatan: Pustaka Excel dan grafik memerlukan internet. Ini adalah website statis yang
siap dicoba dan diunggah. Agar punya link publik seperti website teman, folder ini
perlu diunggah ke akun GitHub milikmu dan GitHub Pages diaktifkan. Website belum
dipublikasikan ke internet dan belum terhubung ke akun GitHub kamu.
